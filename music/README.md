# Tu música de fondo

Pon aquí canciones (`.mp3`, `.wav`, `.ogg`, `.m4a`, `.flac`) y aparecen en el repertorio de hypertutorial junto a las 8 pistas incluidas:

```bash
node scripts/music.mjs list
```

Estos archivos no se suben a git (ver `.gitignore`): muchas licencias permiten usar la música en tus videos, pero no redistribuir el archivo.

## Dónde conseguir música libre (verifica la licencia de cada pista antes de publicar)

| Biblioteca | Uso comercial | Crédito al autor |
|---|---|---|
| [Pixabay Music](https://pixabay.com/music/) | Sí | No es obligatorio. Algunas pistas tienen Content ID en YouTube: si llega un reclamo, se aclara con la licencia de Pixabay. |
| [Mixkit](https://mixkit.co/free-stock-music/) | Sí, con su licencia gratuita | No. Revisa que la pista no tenga "Restricted License". |
| [YouTube Audio Library](https://studio.youtube.com/) | Las pistas CC BY sí, dando crédito; las de licencia estándar, solo dentro de YouTube | Obligatorio en las pistas CC BY (nombre del artista y enlace en la descripción). |
